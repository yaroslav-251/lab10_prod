шаг 3
строка не изменяется потому что метод возвращает копию строки
шаг 8 
При использовании += на каждой итерации создаётся новая строка, в которую копируется предыдущий текст и добавляется новое число.
StringBuilder позволяет добавлять текст в один изменяемый объект
с помощью Append(), поэтому он удобнее при сборке большого текста в циклах.
контрольные вопросы
1. Неизменяемость string — строку нельзя изменить после создания. text.ToUpper() вернёт новую строку, но без сохранения результата исходная не изменится
2. text[index] и Length — text[index] возвращает символ типа char, а Length — количество символов в строке
3. Split() — разбивает строку на массив строк string[] по указанному разделителю
4. StringBuilder — удобен для сборки текста, потому что позволяет добавлять текст без создания новой строки при каждом добавлении
5. Append() и ToUpper() — Append() изменяет содержимое StringBuilder, а ToUpper() возвращает новую строку, не изменяя исходную
6. $"{value,10:N2}" — выводит значение в поле шириной 10 символов, выравнивает вправо и показывает два знака после запятой с разделителями тысяч
7. F2 и N2 — оба формата показывают два знака после запятой, но N2 дополнительно разделяет большие числа на группы
8. StringBuilder в цикле — позволяет многократно добавлять текст в один объект, избегая постоянного создания новых строк
